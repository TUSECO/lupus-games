### LupuS Games

**Games:**

- FlappyBird (Temporarily removed)
- Chess
- TicTacToe
- Snake
- MineSweeper

**Dependencies:**

- PyQt6
- pygame
- noise

```bash
# Clone Repository
git clone https://github.com/Antolun/lupus-games
cd lupus-games

# Start Build
cd example-game
chmod +x ./build-pisi.sh
sudo ./build-pisi.sh

# Install Package
sudo pisi it ./example-game-*-x86_64.pisi
```
