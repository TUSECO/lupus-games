### LupuS Games

**Games:**
- FlappyBird
- Chess
- TicTacToe
- Snake
- MineSweeper

**Dependencies:**
- PyQt6
- pygame
- noise

```bash
# Install
chmod +x ./install.sh
./install.sh install

# Uninstall
chmod +x ./install.sh
./install.sh uninstall

# Reinstall
chmod +x ./install.sh
./install.sh reinstall
```
