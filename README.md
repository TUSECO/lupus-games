### LupuS Games

**Games:**

- Chess
- TicTacToe
- Snake
- MineSweeper

**Dependencies:**

- PyQt6
- pygame
- noise

```bash
# Clone Repository
git clone https://github.com/TUSECO/lupus-games
cd lupus-games

# Start Build
cd example-game
chmod +x ./build-luppo.sh
sudo ./build-luppo.sh

# Install Package
sudo luppo it ./example-game-*-x86_64.luppo
```
